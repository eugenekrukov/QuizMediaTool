# Quiz Media Tool — Design Brief для дизайнера

## Что это за приложение

Веб-инструмент для авторов квизов. Пользователь ищет треки на YouTube, скачивает их, расставляет маркеры (регионы) на волновой форме и экспортирует нарезанные отрезки. Аудитория: один пользователь локально, не публичный сервис.

Стек: React 19 + Vite, WaveSurfer.js v7 (waveform), FastAPI (бэкенд на localhost:8000).

## Технические ограничения — НЕ МЕНЯТЬ

### 1. WaveSurfer canvas
- `<div ref={containerRef}>` — контейнер waveform. WaveSurfer рисует внутри canvas через своё API.
- **Нельзя**: добавлять дочерние элементы внутрь этого div, накладывать поверх абсолютно спозиционированные блоки с `pointer-events: auto` (перехватят клики с waveform).
- **Можно**: менять размеры контейнера (ширина 100%, высота фиксированная), цвет волны (`waveColor`, `progressColor`) передаётся в WaveSurfer как параметр при инициализации — это JS-константы в `App.jsx`, не CSS.
- Минимальная высота контейнера: **80px**, рекомендуемая: **96–128px**.

### 2. Цвета регионов (RegionsPlugin)
- Регионы рисуются как `<div>` поверх canvas с inline-стилями от WaveSurfer. Цвет задаётся при создании региона как `rgba(...)` в JS-коде. Дизайнер может предложить палитру цветов регионов — разработчик применит их в JS.

### 3. Видеоплеер
- `<video ref={videoRef}>` должен присутствовать в DOM и быть видимым при выборе MP4-файла. Без этого синхронизация `currentTime` ломается.
- Можно: менять размер, скруглять углы, добавлять обёртку/рамку.
- Нельзя: скрывать через `display:none` или `visibility:hidden`.

### 4. YouTube embed
- `<iframe src="https://www.youtube.com/embed/{id}?autoplay=1">` — нельзя обернуть в элемент, перехватывающий клики. Пропорции фиксированы: `aspect-ratio: 16/9`.

## Компоненты и их состояния

### Левая панель

**Табы переключения**
- Два варианта: «🔍 Поиск» и «🔗 По ссылке»
- Состояния: обычный, активный (текущий), hover
- Активный таб должен визуально выделяться (цвет, подчёркивание, фон)

**Поиск (таб «Поиск»)**
- Поле ввода + кнопка «Найти» (или поиск по Enter)
- Состояние загрузки: spinner / disabled input
- Карточка результата:
  - Миниатюра (120×67px, `mqdefault.jpg` — фикс. соотношение 16:9)
  - Название (2 строки максимум, overflow: ellipsis)
  - Канал (1 строка, второстепенный текст)
  - Длительность (правый угол или под названием)
  - Кнопки: «MP3» и «MP4» (два варианта скачивания)
  - Состояния кнопок: обычный, загрузка (spinner), disabled пока грузится
  - Клик по миниатюре/названию → открывает превью в правой панели

**По ссылке (таб «По ссылке»)**
- Textarea для вставки YouTube-ссылок (одна или несколько, по одной на строку)
- Радио/сегмент: «Аудио (MP3)» / «Видео (MP4)»
- Кнопка «Скачать»
- Прогресс загрузки (текстовый статус)

**Список скачанных файлов**
- Всегда виден в нижней части левой панели (или в отдельной прокручиваемой секции)
- Каждый файл: иконка типа (🎵/🎬) + имя файла (truncate) + кнопка удаления
- Активный файл (открытый в редакторе) выделяется
- Состояния: обычный, активный, hover

### Правая панель — Редактор

**Шапка редактора**
- Название текущего файла
- Кнопки: «▶ Воспроизвести» / «⏸ Пауза» (единая кнопка), «⏮ Начало»
- Таймер: `текущее_время / общая_длина` (формат `MM:SS`)

**Waveform-зона**
- Контейнер WaveSurfer (canvas внутри)
- Под waveform или сбоку: инструменты работы с регионами

**Регионы (маркеры)**
- Кнопка «Добавить регион» — создаёт регион на текущей позиции
- Список регионов: start–end, кнопки «▶ Прослушать» и «🗑 Удалить»
- Кнопка «💾 Зафиксировать» — сохраняет текущие регионы для этого трека

**Зафиксированные отрезки**
- Список (по трекам) зафиксированных регионов
- Каждый отрезок: имя трека + время старта + кнопка удалить из списка
- Кнопка «📤 Экспортировать всё» — нарезает и сохраняет файлы

### Правая панель — Превью YouTube

- Шапка: название видео, кнопки «🎵 Скачать MP3» и «🎬 Скачать MP4», кнопка «✕ Закрыть»
- iframe (16:9, максимальная ширина 900px)

## Токены и CSS-переменные

Весь цвет приложения должен задаваться через CSS-переменные (уже заведены в коде):

```css
:root {
  --bg: #0a0a0a;        /* фон приложения */
  --bg2: #111;          /* фон панелей / карточек */
  --bg3: #1a1a1a;       /* фон полей ввода */
  --border: #2a2a2a;    /* границы */
  --text: #e8e8e8;      /* основной текст */
  --text2: #888;        /* второстепенный текст */
  --acc: #7c5cfc;       /* акцентный цвет (фиолетовый) */
  --acc2: #5c3fd4;      /* акцент тёмный / hover */
  --danger: #e05252;    /* деструктивные действия */
  --success: #52a852;   /* успех */
}
```

Дизайнер может предложить новые значения для этих переменных или добавить новые.

WaveSurfer-специфичные цвета (передаются в JS при инициализации):
- `waveColor`: цвет не воспроизведённой части волны
- `progressColor`: цвет воспроизведённой части

## Что дизайнер может делать свободно

- Менять значения CSS-переменных (тема, палитра)
- Предлагать типографику (font-family, размеры, веса)
- Менять отступы, скругления, тени
- Реструктурировать layout внутри панелей (порядок блоков)
- Добавлять иконки (SVG или Unicode emoji → потом заменим на SVG)
- Предлагать анимации (CSS transitions/keyframes)
- Изменять размер левой панели (сейчас 300px, можно 280–360px)

## Что требует согласования

- Скрытие/перемещение `<div ref={containerRef}>` (WaveSurfer)
- Скрытие `<video ref={videoRef}>` (синхронизация сломается)
- Добавление кликабельных элементов поверх waveform
- Изменение структуры JSX (порядок ref-элементов)

---

## Формат передачи результата

Идеально: обновлённые значения CSS-переменных + описание изменений в разметке словами. Разработчик применит изменения в `App.jsx`, не трогая логику.

Альтернативно: HTML-мокап с теми же CSS-переменными — разработчик перенесёт стили.

**Не нужно**: передавать Figma-файл, React-компоненты или готовый JSX — разработчик реализует сам по визуальному описанию.
